# ARTEX iOS 开发状态

更新：2026-11-11。

## 当前实现

客户端采用 iOS 26 起的 SwiftUI 原生界面，支持 Tasks、Sessions、主对话及 Findings。界面使用紧凑排版，导航和输入栏使用系统玻璃效果。

代码已整合到 ARTEX 仓库的 `ios/` 目录。首次使用需自行添加 HTTPS 远程源；演示模式使用隔离的虚构数据。工程不附带部署记录、设备标识、个人签名团队或一次性凭据文件。

后端设备 Token 实现位于根目录 `db/` 和 `server/`：随机 256 位 Token、只保存摘要、90 天有效期上限、30 天闲置失效、密码变更失效及单设备撤销。活动流每 15 秒重新验证，撤销后断开。测试覆盖生命周期、接口权限和签发限制。

## 验证方式

- `swift test` 验证 API 请求、URL 校验、数据解析、SSE 和写操作错误处理。
- Xcode 模拟器构建验证完整 SwiftUI App。
- `UITests/` 使用 `--demo` 验证 Tasks → Sessions → Hint 及 Findings/创建任务流程。
- 后端测试需独立 PostgreSQL 实例，禁止对生产库运行。相关测试名称以 `TestMobile` 开头。
